# 姐妹图集：电脑布局评审稿

独立本地示意页，不是线上发布目录。原 `../publish/` 未修改。

设计方向：保留暖白底、砖红点缀和轻松语气，以图片为主。设计变化 3/10，动效 2/10，内容密度 7/10；沿用现有原生 HTML/CSS/JS 和 Phosphor 图标。

- 页面可用宽度达到 1000px 时，使用固定左侧导航，右侧展示原来的四个分区。
- 1000–1199px 展示三列；1200–1679px 展示四列；1680px 起展示五列。超宽屏限制内容宽度，避免图片无限拉宽。
- 顶栏和分区工具条在电脑端随滚动保持可见；增大文字和操作目标，压缩介绍区。
- 电脑大图采用左图右操作布局，保留原尺寸查看、多图翻页和收藏、保存图片功能。
- 窄容器自动收起侧栏，使用底部导航；手机维持双列和全屏看图。断点取决于页面容器可用宽度。
- 原有分类、JS 数据流程及权限逻辑保持原样。此副本的 config.js 为空 API 地址，只显示本地示例数据，上传和收藏刷新后清空。

## 本地打开

在仓库根目录执行：

```powershell
python -m http.server 8776 --bind 127.0.0.1 --directory gamefy-comic/desktop-proposal
```

访问 http://127.0.0.1:8776/ 。
