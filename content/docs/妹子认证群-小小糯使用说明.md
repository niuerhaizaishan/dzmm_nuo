# 🌸 小小糯 使用说明

> **适用群：认证妹子群（男、游客直接踢出）**
> 小小糯是群里的常驻小秘书，19 岁，银白双马尾、红蓝异色瞳，说话软软糯糯带"～"和"♡"。
> 她所有回复前面都带一个 **🤖**，看到 🤖 就是她在说话。

## 一、三步上手

| 步骤 | 做什么 | 怎么发 |
|---|---|---|
| 1️⃣ | **跟她说话** | `@小小糯～` + 你想说的话 |
| 2️⃣ | **建个档案** | `/注册` |
| 3️⃣ | **看全部功能** | `/说明` |

建档之后，别人 `/查` 你会丰富很多（有画像、性癖、最近发言），`/算命` 也会准一些。

## 二、指令总表

### 💬 聊天 & 记忆

| 指令 | 作用 |
|---|---|
| `@小小糯～` + 内容 | 直接跟她聊天，她会结合群聊上下文和记忆回你 |
| `@小小糯 记住 XXX` | 用大白话让她记事，例：`@小小糯 记住 我喜欢吃芒果` |
| `/记住 内容` | 同上，指令版 |
| `/回忆` | 列出她记住的所有事（原文，最多显示最近 8 条） |
| `/自我介绍` | 让她自我介绍 |
| `/说明` | 功能说明（就是本文的简版）；别名 `/使用说明` `/功能` `/指南` `/帮助` `/菜单` `/指令` |

> 记忆上限 **100 条**，超了会自动淘汰最旧的。

### 📇 档案

| 指令 | 作用 |
|---|---|
| `/注册` | 给自己建档（拉资料 + 生成画像，约 15 秒） |
| `/注册 昵称` | 替别人建档（**仅糯糯姐可用**） |
| `/查 昵称` | 查某人档案卡（昵称/性别/签名/简介/性癖/注册画像/最近发言） |
| `/同步` | 手动同步全群成员档案（**仅糯糯姐可用**） |

> 查过的人如果改名、改简介、改签名，小小糯会自动发现并更新档案；下次 `/查` 会带上**变化轨迹**（"以前叫 XX，简介写的是 XX"）。

### 🔮 运势 & 诗词

| 指令 | 作用 |
|---|---|
| `/算命`（别名 `/运势` `/占卜` `/今日运势` `/运气`） | 按**五行命理**算今日运势 |
| `/写诗`（别名 `/作诗` `/赋诗`） | 随机文学方向，结合档案+发言写一首短诗 |
| `/写诗 主题` | 指定主题写 |

**运势怎么算的**：`命基（本命五行）+ 名格生克 + 本命生克 + 日冲/日合 + 人和`，
再给出四维分数（💰财运 · 💼事业 · 💗感情 · 🩺健康）和幸运色/数字/方位。
- **同一个人同一天分数固定**，不会刷新变高变低
- 「⚠ 日冲本命」= 本命地支与当日六冲，**是真正的凶日**
- 等级：大吉 90+ ｜ 吉 80+ ｜ 中吉 70+ ｜ 小吉 60+ ｜ 平 40+ ｜ 小凶 20+ ｜ 凶 20 以下

## 四、发情值怎么涨

| 行为 | 涨多少 |
|---|---|
| 被羞辱 | +15 |
| 发骚骰子（被点到的 / 点人的） | +10 ~ +15 |
| 被调教一轮 | +20 |
| 参与剧情 | +8 ~ +15 |
| 参与公演 | +8 ~ +15 |

发情值**持续累加**，满 **100** 触发一次高潮事件，触发后**扣掉 100**（多出来的部分保留，继续累积）。
"今日高潮次数"每天 0 点重置，用于骚度排行。

> 例：发情值 118 → 触发高潮 → 剩 18。

## 六、玩法互斥（重要）

**同一时间只能进行一个"大玩法"**。进行中发别的指令会被挡下来：

| 正在进行的 | 发别的指令会得到 |
|---|---|
| 发骚 | "🎲 发骚过程中暂时无法响应其他指令哦～" |
| 调教 | "🔗 调教进行中哦～想参与就发 /命令 xxx" |
| 公演 | "🎭 公演进行中哦～想参与就直接发言" |
| 剧情 | "🎬 剧情进行中哦～想投票就发 /选 1/2/3" |
| 投票 | "📊 投票进行中哦～想参与就发 /选 X" |

想切换玩法，先发 `/结束`。

## 七、常见问题

**Q：指令没反应？**
A：检查三件事 —— ① 斜杠后面**不要加空格**（`/查 清歌` ✅，`/ 清歌` ❌）；② 是不是有玩法正在进行中（见上一节）；③ 是不是撞上平台风控了（小小糯会提示）。

**Q：`/发骚` 必须指定人吗？**
A：不指定就随机点一位群成员。

**Q：她记错事 / 记了不想记的？**
A：用 `/回忆` 看记了什么，然后找糯糯姐手动清理。

**Q：运势偏低怎么办？**
A：运势按五行确定性计算，同一天分数不会变。低分那天就照「宜忌」来，小小糯会用心疼的语气陪你过。

**Q：为什么她有时候不说话？**
A：她只在**被 @、有人进群、或你发指令**时回应，不会乱插话。想让群冷清时她也冒泡，发 `/吐槽开`。
