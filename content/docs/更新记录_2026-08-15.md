# 小小糯 DZMM Bot 功能更新记录

**日期**：2026-08-15

---

## 一、发情值养成系统（核心更新）

### 1. 系统升级

把原来的「骚度排行」（AI 一次性打分前 5 名）升级为「发情值养成系统」，整合三个组件：

- **发情值**：每人一个 0→100 的养成积分，衡量"发情/骚"程度
- **高潮事件**：发情值涨满 100 触发专属色色文字，清零重来
- **骚度排行**：按发情值排（发情值为主、活跃度为辅）

### 2. 发情值三条涨分途径

| 途径 | 触发方式 | 加分 |
|------|---------|:----:|
| ① 说骚话 | 每 2 小时 AI 批量评定发言发情程度 | 0~30 |
| ② 与小小糯互动 | 被羞辱 `/羞辱`、`/发骚` 随机抽或指定、 `/体位骰` | +15 |
| ③  公演 | 参与公演 | +15～30/次 |
|  |  |  |

### 3. 高潮事件

- 发情值 ≥100 → 专属色色文字（比体位骰更直白露骨）+ @当事人
- 触发后清零重来（保留溢出），高潮次数 +1

### 4. 骚度排行

- 排序：发情值降序为主，活跃度（发言次数）降序为辅
- 排除小小糯
- 展示：`🥇 过期少女 —— 发情值 68 · 活跃 130条 · 高潮 0次`

### 5. 发布规则

- 有人发情值达到 100 → 立即触发高潮 + 群内提醒 + 发布排名
- 没人达到 100 → 每天 **12:00 和 18:00** 定时发布排名

## 二、"发骚"指令重构

原来 `/发骚` 是「场景骰子」的别名（`is_scene_cmd` 里排第一），与新功能"发骚点名"语义冲突。已拆分：

- **`/发骚`** → 独立为「发骚点名」指令：随机抽或指定某人发骚，加发情值 +15
- **场景骰子** → 只保留 `/体位骰`、`/场景骰`、`/涩涩骰`
