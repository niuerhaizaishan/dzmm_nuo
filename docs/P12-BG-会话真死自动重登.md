# P12-BG：会话"真死"时自动升级到密码重登（不再瞎一个小时）

> 屋主 2026-09-30 13:33："**妹子群怎么不自动踢人了？**" → 查出来是账号会话死了 64 分钟
> 屋主随后："**升级**"

## 1. 现场（不是踢人坏了，是会话死了）

```
12:23:05  SESSION_DEAD: 业务调用也未授权（会话真失效），写 emergency 触发重登
12:23~13:13  ⚠️ 平台读消息失败：Invalid authentication credentials（每 10 分钟一次）
13:12     用户c9da03 加入了群聊              ← 她根本没看见 ⇒ 没筛查、没踢人
13:23     又一轮失败 → probe: unauth → 再次 emergency 重启（只重启了 bot.py 进程）
13:27     人工在容器里跑 headless_relogin.py → 会话立刻恢复
13:29:14  🎉 [bd7fe6a4] 新成员加入 1 人，开始筛查 → 补上了那条 13:12 的入群
```

**为什么"只有踢人停"**：踢人要先**读群 + 查成员资料**（都走账号会话）；
而发消息走 **Bot 通道**（一直正常）⇒ 群友看到的是"她还会答 /运势，就是不踢人了"。
那一小时里积压消息的投递延迟到了 **3954 秒（66 分钟）**。

分层诊断（`tools/probe_session_layers.py`）：

| 层 | 结果 | 含义 |
|---|---|---|
| ① 首页 | 200 ✅ | **不是 IP 级风控**（不是 418 验证码墙） |
| ② `/api/auth/token` | **401 未授权**，无 access_token | 手里的会话过期/失效 |
| ③ 业务调用（读群） | `Invalid authentication credentials` | **会话真死**（不是只读接口的常态 401） |

## 2. 根因：自动路径**不会升级手段**

| 谁 | 每多久 | 会做什么 | 为什么救不回来 |
|---|---|---|---|
| `renew_token.py` | 5 分钟 | 先浏览器刷新，再写 `token.emergency` | 浏览器刷新只在 **refresh_token 还有效**时管用；会话真死时它换不出东西 |
| `token.emergency` | — | 让 **bot.py 进程**退出重启 | **不重启容器** ⇒ entrypoint 里那句 `headless_relogin.py` 不再执行 |
| `headless_relogin.py` | 只在**容器启动**时 | 密码登录（唯一能救活死会话的手段） | 平时根本不会被调用 ⇒ 只能等人 |

⇒ 每次会话真死都得**人工**进容器跑一次密码登录（09-28、09-29 那两次长时间掉线也是同一个坑）。

## 3. 修法：升级链（`renew_token.py`）

```
会话真死（业务探针 unauth）或连续 RELOGIN_AFTER_MIN=20 分钟没验证通过
  ├─ 浏览器刷新（现状：能救就救，不重启）
  ├─ **自动跑 headless_relogin.py 密码重登**（P12-BG 新增）
  │    · 冷却：30 分钟最多一次（别把风控刷起来）
  │    · 起步门槛：会话连续坏 ≥5 分钟（一次抖动的 401 不重登）
  │    · 成功判定**不看它自己的输出**，而是再打一次业务探针 == ok
  │    · 成功 ⇒ 清退避文件 + 写会话 ok + **不重启 bot**
  │        （保住常驻页面与出站队列；Socket.IO 也能立刻重连）
  │    · 撞验证码 ⇒ `headless_relogin.py` 自己拉 noVNC 人工辅助 + 发微信（本来就有）
  └─ 都不行 ⇒ 落回原来的 `token.emergency` 重启（兜底不变）
```

为什么"清退避"很重要：`sio_subscribe._token_stale()` 会在会话被判死时把重连退避
一路顶到 **2560 秒** —— 今天会话恢复后 Socket.IO 还白等了十几分钟才连上。

日志：`ESCALATE: 会话不可用 → 自动跑一次密码重登（headless_relogin.py）`（只进日志，不发微信）、
`OK: 密码重登成功，会话已恢复（未重启 bot，退避已清）`（**发**微信，让你知道刚才出过事）。

## 5. 效果

| | 以前 | 现在 |
|---|---|---|
| 会话真死 → 恢复 | **人工**，平均 ~1 小时（09-28/29 各一次） | **自动**，首轮探针 + 登录 ≈ 1~3 分钟 |
| 恢复代价 | 重启 bot（丢在途消息，见 P12-BC） | **不重启**（保住常驻页面/出站队列） |
| Socket.IO 重连 | 按 2560s 退避白等 | 退避被清，立刻重连 |
| 撞验证码 | 静默空转 | noVNC + 微信通知（原路径）+ 升级链不空转 |
