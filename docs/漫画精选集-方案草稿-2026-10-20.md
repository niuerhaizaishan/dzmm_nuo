# 姐妹图集：当前需求与实现（2026-10-20）

本文件替代早期正式漫画书架方案，以用户最新确认的图片共享方式为准。

## 已确认范围

- 整个功能仅限当前妹子认证群成员，包括查看和原图下载。
- 以图片为主，四个分区：个人立绘、姐妹日常、高清美图、大开脑洞。
- 两种收图入口共用数据：群里回复原图 `/保存 分区名`，或在小游戏内直接上传。
- 群内 `/漫画` 分两条发送：介绍文本，以及 `type=share`、`shareType=character`、`resourceId="3799187"` 的游戏分享卡。玩家链接为 https://www.dzmm.ai/character/3799187 。
- 配文可选，不要求漫画标题、作者介绍、分类标签或图册发布会话。

## 本地实现

群指令在 `runtime/mainloop.py` 和 `runtime/dispatch.py` 接入；`runtime/gallery.py` 负责当前成员核验、回查引用原图、限定来源下载、格式/大小检查和 SQLite 持久化。原始图片 BLOB 与元信息在同一事务保存，同分区 SHA-256 去重，成功落库后才反馈已保存。机器人回执失败重试也不会重复收录。

`runtime/gallery_api.py` 提供列表、受保护原图、收藏和网页上传。Gamefy 玩家 JWT 验签与当前群成员检查作用于每一个 API 请求。历史发言和 `known_members` 不作为授权依据；无法可靠核验时拒绝访问。原图不进入匿名静态目录或游戏发布包。

网页位于 `gamefy-comic/publish/`，保留图片流、搜索、收藏、大图与上传界面。正式接口将每张图片独立收进分区。没有服务且无 SDK 的本地页面仅供演示；平台中验证失败不会显示演示数据。
