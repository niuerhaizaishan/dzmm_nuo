# 图集下载函数冲突修复

保存图片时出现 `dialog.showModal is not a function` 或 `dialog.setAttribute is not a function`，根因是单文件 HTML 中顶层声明的 `function open(dialog)` 覆盖浏览器 `window.open`。下载按钮把原图 URL 传给弹窗函数，字符串无法执行 DOM 方法。`function close` 同样污染了浏览器全局对象。之前依据这些错误推断宿主不支持 dialog 不成立；这些错误发生在点击调用时，也不能证明初始化和所有事件绑定都中断。

修复：弹窗函数改名 `openGalleryDialog` / `closeGalleryDialog`，应用脚本封装在立即执行函数内，保留浏览器 `window.open` / `window.close`。支持原生 dialog 时使用原生模态弹窗；兼容回退关闭时补发 close 事件，保持视频暂停与清空源地址。`noopener` 打开成功也可能返回 null，不再据此报告弹窗被拦截。

验证使用完整构建 HTML 在 JSDOM 中执行所有内联脚本。旧包可复现 setAttribute TypeError；新包在原生 dialog 模拟和无 dialog API 两种条件下通过：浏览器全局函数保持、下载图片 78 调用带 attachment 参数的原图地址、上传/详情/说明弹窗开关、关闭视频清理、私密原图获取带 Authorization。此为 DOM 模拟检查，不等于 Gamefy 宿主真实下载验证；私密 Blob 下载和宿主弹出窗口策略仍需线上验证。

交付：`tmp_gallery_deploy/download-scope-fix/gamefy-download-scope-fix.zip`，条目仅 `gallery/publish/index.html`；打包字节一致性和摘要见同目录 `verification.json`。本次未更改后端或生产图集数据，前端需在 Gamefy 工坊重新发布。
