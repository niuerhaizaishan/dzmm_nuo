# 认证妹子群聊天归档

仅支持 PRIMARY_CID 指定的认证妹子群。茶水间、其他群和私聊均不记录，不提供定时清理，不自动删除旧消息。

## 保存字段

| 字段 | 含义 |
|---|---|
| group_id、message_id | 群和平台消息 ID，联合唯一键 |
| sender_id | 平台原始 UID，用于区分同名成员和关联改名后的消息 |
| sender_name、name_source | 这条记录里的昵称和来源；不全局覆盖旧昵称 |
| sent_at、sent_at_original | UTC 时间戳和源时间字符串，查询界面显示北京时间 |
| message_type、text | 文本、系统消息、图片、语音、表情、分享、撤回等类型和源文本 |
| content_json | 接收时已有的内容对象，可包含引用、@或附件元数据；不主动下载附件 |
| source、source_file_sha256、archived_at | 导入/实时推送/HTTP 补拉来源、导入文件校验和和落盘时间 |

昵称来源分三种：消息自带、采集时的成员昵称缓存、历史文件导出的 name。历史文件没有说明 name 的解析时点，所以不声称它一定是发送时昵称；未找到昵称时保留空值，页面显示“昵称未知”，UID 仍可查询。导入时不调用平台重新查名，也不以当前昵称重写历史。

归档使用 data/chat_archive.db，与 store.db 和 outbox.db 分开，WAL 并发读写。数据库、WAL 和 SHM 在 Linux 设置为 0600；Windows 使用所在目录的账户权限。data/ 已被 Git 和 Docker 构建上下文排除；原始历史文件不纳入源码提交，不送进 AI 或第三方服务。

## 历史导入

本次提供的 JSONL 每行字段为 id、sent_at、bj、uid、name、type、text，共 21,306 条，无重复 ID。文件没有群 ID，因此命令必须显式声明认证群归属；若行内另外携带了其他群 ID，则拒绝并回滚整次导入。

```powershell
python -X utf8 tools/active/import_chat_archive.py "D:\Deepseek\认证妹子群-全量聊天记录-20260727至20261007.jsonl" --group bd7fe6a4-0065-4551-ad3d-94116dba8f9c
```

支持 --db 指定本地归档路径。不读取现有凭据、不登录平台、不发送群消息。导入逐行读取，以文件 SHA-256 和文件名登记来源；坏 JSON、缺 ID 或无效时间会使整次消息插入回滚。重复导入或推送/HTTP 重叠按消息 ID 忽略，不把“同内容不同 ID”的真实重复发言误删。

时间以 sent_at 为准，bj 是导出文件的派生显示值，不额外参与排序；无时区实时时间按当前平台接口约定的 UTC 解释。原文件不修改，未包含的附件地址、引用和 @ 信息无法从这份导出中恢复。

## 新消息接入

DZMM_CHAT_ARCHIVE 默认 off，设为 on 才开始落盘。生产 compose 已加入该键透传，默认仍为 off；本次没有部署、重启、启用线上采集或提交代码。自定义路径可使用 DZMM_CHAT_ARCHIVE_DB；生产推荐默认 data/ 目录挂载，当前 compose 不透传自定义路径变量。

采集点在主循环取得消息后、游标/指令/自身消息过滤之前，因此包含本次读到的群友消息、机器人回声、系统与非文本消息。只在认证群生效；直接记录消息接收端读到的批次，不从 Outbox 复制尚未确认投递的文字。

写库在工作线程中进行，短连接、不建立另一套浏览器或长期内存消息缓存。数据库锁等待上限 0.25 秒，写入故障或无效行只输出限量诊断，错误日志不输出消息正文；不改变指令处理、判死或恢复决策。SQLite 写入本身无严格耗时上限。

这不是完整可靠投递协议：停机、推送丢失、HTTP 最近 20 条窗口之外的消息、归档写入故障可能产生缺口，本轮不增加自动追补任务。是否写入不影响现有业务游标；不得把“已读批次归档”称为“全量无漏”。后续若要求完整性，需要另做分页追补和缺口检查。

本轮保留首次收到的记录，同 ID 后续编辑/撤回不自动覆盖原文；历史文件自身已有的 recalled/deleted 行会以该类型保存。平台撤回事件是否进入普通消息流没有保证，不能据此判定实时撤回状态。

## 后台只读查询

运维后台新增 /messages，仅展示认证妹子群。沿用后台现有登录、响应安全头和 no-store；未配置密码时遵循既有仅回环/隧道模式，不新增公网端口。

支持北京时间起止日期（包含结束日）、昵称包含、精确 UID 和字面关键词筛选，每页 50 条，最近消息在前；长内容可展开。数据库始终以 mode=ro 打开；不存在时显示尚无归档，不新建空库。内容、昵称、搜索条件均进行 HTML 转义，不加载附件链接或外部资源。

本地历史库已经保存并可查询；线上库和实时采集须另行部署和导入，源码发布不携带数据库。
