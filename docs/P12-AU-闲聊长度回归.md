# P12-AU：闲聊回复变短（收尾块把"话题锚点"读成了"少说话"）

> 屋主 2026-09-29 晚："**茶水间@小小糯 闲聊回复变短了！**"

## 1. 先量：确实短了，而且短在晚上

从平台读原件（日志里回复被截到 200 字，量不准）：

```
18:43  32 字   🤖 琰晏哥哥来啦～欢迎欢迎，今天群里挺热闹的，要一起玩点什么吗？
18:44  60 字   🤖 琰晏哥哥～糯糯姐那也是为我好嘛…
18:45  43 字   🤖 古明地恋哥哥晚上好呀～吃晚饭了没有？这个点还在群里晃…
```

## 2. 再定位：嫌疑人是我自己两个改动

P12-AP/P12-AQ 为了治"摸摸头被读成糯糯冒头""空手编待办"，往提示词和收尾块里加了一批
**克制**规则（"只回这一句""没有实质内容就只接住这一句""别接着上一轮讲""没人问就别汇报"）。
把两处改动拆开量（同一批闲聊问题、各 3 次采样，`tools/probe_reply_length_ab.py`）：

| 变体 | 均值 | 中位 | 短于100字 |
|---|---|---|---|
| A 旧提示词 + 无收尾块（改动前） | 122 | 115 | 3/15 |
| B 新提示词 + 无收尾块 | 89 | 90 | 8/15 |
| C 新提示词 + 收尾块（线上） | **55** | **46** | **15/15** |

结论：**主犯是收尾块**（B→C 又砍掉 38%）。提示词规则也有影响但小得多。

## 3. 根因：一句话背了两个意思

收尾块原来写的是：

```
【怎么回】只回他这一句。…有实质内容就答这件事本身，没有实质内容（摸摸头/抱抱/打个招呼/
         只叫你名字/发个表情）就只接住这一句，别接着上一轮那件事往下讲。
```

这句话的**本意是话题锚点**（别接着上一轮讲、别把人认错），但"只回""只接住这一句"
在模型眼里同时是**篇幅指令**。于是"晚上好呀"这种寒暄被归进"没实质内容"那一类 → 三四十字打发。

## 4. 修法：把"话题"和"篇幅"拆成两条

`prompts/AT_FRAME_PROMPT.md`（+ `brains.AT_FRAME_PROMPT`，逐字节一致）新结构：

```
【怎么回】话题只接他这一句：他说什么你答什么，别接着上一轮那件事往下讲；
         他就是「{who}」，不是聊天记录里的任何人 —— 别因为这句话亲昵就认定对方是别人。
【写多长】长度按内容来，**别用一两个短句把人打发了**：问你今天怎么样、在干嘛、吃了没、
         群里热不热闹，这些都算有内容 —— 照人设正常聊开，2~6 句、100~300 字起步，
         值得展开就写更多。**只有**纯贴贴或纯招呼（摸摸头、抱抱、只叫你名字、发个表情）
         才允许一两句接住。
```

`CMD_PROMPT` 里那条也同步改口径：从"他这句话没有实质内容时…一两句接住"改成
"**只有"纯贴贴/纯招呼"才可以短回**；⚠️ **正常寒暄不算这一类**"。

防编造那段（`{pending}` / 不许编）**原样保留** —— 它跟长度无关，删了就会复发 P12-AQ。

## 5. 验收

| | 修前 | 修后 | 改动前基线 |
|---|---|---|---|
| 闲聊回复均值（15 次采样） | **55 字** | **166 字** | 114 字 |
| 短于 100 字 | 15/15 | **1/15** | 7/15 |
| 行为回归（认亲/念待办/编造，4 场景 × 5 采样） | — | **0/20 违规** | — |

**两件都要看**：光把长度调回来很容易把"摸摸头不再被读成糯糯冒头""空手不编待办"一起弄丢，
所以验收必须同时跑 `probe_reply_length_ab.py`（长度）和 `probe_at_focus.py`（行为）。

测试：`tests/test_at_focus.py` 新增 3 条 —— 收尾块必须把【写多长】单独成条、
必须点名"哪些算有内容"、`CMD_PROMPT` 必须写清"正常寒暄不算这一类"；
收尾块长度上限 420 → 460（加的是这次修复的本体，属必须留的固定开销）。

## 6. 复盘

- **"约束行为"的句子会顺带约束篇幅**：写法上"只回这一句"这种话，模型会同时当作
  话题范围和字数上限。**一个字段一个意思**，别让一句话背两个约束。
- **加限制性规则时必须量副作用**：P12-AP/AQ 修的是"该不该说那些事"，
  但我没量"那还说不说话"。修复一个行为时要顺手量相邻的另一个行为
  （这里是长度），否则就是按下葫芦浮起瓢。
- **探针要自带夹具**：上一版 `probe_at_focus.py` 每次从线上最近 1200 条里捞那条"摸摸头"，
  一小时后它就滚没了 → 探针以"找不到"收场。那不是问题消失，是**探针过期**。
  现在内置了复刻当时上下文的 `SYNTH_HIST`，随时可回归。
