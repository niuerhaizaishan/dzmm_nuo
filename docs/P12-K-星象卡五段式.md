# P12-K：玫瑰房星象卡改「五段式」（模板口径）

> 起因：2026-09-26 屋主给了一张星座运势模板图（`@用户 ♉ 金牛座今日运势` +
> 【综合运势】【爱情运势】【事业学业】【财富运势】【健康运势】五段 + 三行
> `幸运颜色/幸运数字/速配星座`），要求玫瑰房的星象输出照这个格式来。
> 定稿口径（屋主选）：**保留原来的分数与宜忌打头**，后面接五段正文，
> 末尾补齐幸运三件套。

## 1. 卡片长什么样

```
🌹 今日星象 · ♉ 金牛座
————————————
🪐 土象 · 守护星金星 · 月相：盈凸月 · 04-25生
💗爱情78 · 💼事业85 · 💰财运70 · 🌙心情52
🍀 幸运：祖母绿耳坠 · 西南
📅 宜独处 ｜ 忌翻旧账
————————————
【综合运势】今天适合把节奏放慢一点，别急着替所有人收尾…
【爱情运势】单身的人别急着回应示好，先看清对方的态度…
【事业学业】上午先做最需要专注的那件，下午再回消息…
【财富运势】该花的钱别省，不该垫的情分也别垫…
【健康运势】久坐记得起身走动，晚上少喝一杯…

♉ 幸运颜色：鸦青
♉ 幸运数字：7
♉ 速配星座：摩羯座
```

变化点（相对旧卡，旧卡是 `🌹 今日星象 · 金牛座` + 分数行 + 幸运物·方位·**色** +
宜忌 + **一段**点评，≤10 行）：

| 位置 | 旧 | 新 |
| --- | --- | --- |
| 标题 | `🌹 今日星象 · 金牛座` | 带本座符号 `♉` |
| 幸运行（头部） | 物 · 方位 · **色** | 物 · 方位（色挪到尾巴，不重复） |
| 正文 | 一段 160~240 字 | **五段** 40~70 字/段 |
| 尾巴 | 无 | 幸运颜色 / 幸运数字 / 速配星座（各带符号） |

行数从 ≤10 变 18~20；四维分数、宜忌、星象榜口径**一个字没变**。

## 2. 数据来源（确定性 / AI 分工）

| 卡片元素 | 来源 | 说明 |
| --- | --- | --- |
| 星座、元素、守护星、月相、宜、忌 | 代码常量 | `personas.ROSE_SIGNS` / `ROSE_SIGN_YI` / `ROSE_SIGN_JI` / `ROSE_MOONS` |
| 爱情/事业/财运/心情 四维 | `_sign_calc` 哈希 | 口径未动（星象榜名次不受影响） |
| 综合 | 四维均值 `total` | 同上，未动 |
| **健康分** | `_sign_calc` 新增 `health` | 取 md5 里没用过的片段，同人同日同座必相同 |
| **幸运数字** | `_sign_calc` 新增 `luck["num"]` | 1~9 |
| **速配星座** | `_sign_calc` 新增 `luck["match"]` | `personas.ROSE_SIGN_MATCH` 每座三选一，按日期确定性取 |
| 五段正文 | **AI**（`generate_horoscope`） | 一次调用出五段 |

## 3. 安全网：模型不按格式写怎么办

`runtime/sign.py::_split_sections()` 负责把 AI 输出拆成 `{规范名: 正文}`：

- 认 `【爱情运势】`、`【爱情】`、`爱情运势：`、`1. 【爱情】…`、`[爱情运势]`；
- 换行切段靠 `【` `】` 补换行，所以"五段挤在一行"也能拆开；
- 正文里的"综合来看""财运：…"**不会**被当标签（要求行首/带括号，且必须精确等于别名）；
- 拆出来 **< 3 段就当没认出来** → 退回旧口径：分数 + 宜忌 + 一段点评 + 幸运三件套
  （`one = " ".join(para.split())` 压平）。

**任何情况下卡片都有内容**：LLM 超时/报错/返回空 → 用玫瑰房兜底文案；尾巴三件套
永远照发（它是确定性的）。

## 6. 已知取舍

- **没有加 `@某人`**：模板是群发公告，我们的卡片是回给提问的人；`@` 会额外触发提醒，
  所以称呼（"客人"/"Vv姐姐"）交给正文，标题只带星座符号。
- **长度换信息量**：一张卡 ≈ 450 字，比旧卡长 3 倍。屋主此前要求过玫瑰房回复"丰富一些、
  长一些"，这条与之一致；若嫌长，优先砍【综合运势】（它和头部四维重复度最高）。
- **延迟**：一次调用出五段，输出 token 约为原来的 3~4 倍（旧卡 1.25~1.77s），
  实测以线上日志为准；每段限 40~70 字就是为了压住这段延迟。
