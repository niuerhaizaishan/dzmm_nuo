# P12-AH：若瑾的人情味 / 口语化 / 装饰符

> 屋主 2026-09-27：
> 1. "回复在高冷和 S 中间稍微有点人情味，比如时不时搞搞抽象，开个玩笑之类的。"
> 2. "回复内容中加点儿「！！！❤️❤️❤️❤️」的修饰。"
> 3. "不要太生硬。" 追加："更多口语化，减少书面用语，可能更亲近点。"
>
> 三个决定（当天问过屋主）：❤️ **给糖/认可/收尾约每 2-3 条一次**、
> **玩法正文也挂**、玩笑**每四五条一句冷的**。

## 1. 先诊断：她的"生硬"是写进口径里的

`RUOJIN_EXTRA`（1536 字，追加在 prompt **最末尾**，recency 最强）里原本明确写着
"语气：低、稳、慢半拍；**陈述句多于问句**；句末多是句号"，还有一堆书面词与术语：
**幼态化 / 不求宠 / 白描 / 描述层面 / 教训与惩罚是你的表达方式 / 被撒娇索要 →
淡淡挡回去**。模型照着这段话写，就是"通知体"。
`RUOJIN_PHRASES` 里那批固定话术（"记住了。""查不到这个人。""现在没有进行中的玩法。"）
是另一处生硬来源。

## 2. 改了什么（都在 `personas.py`）

| 维度 | 改法 |
|---|---|
| **口语化** | 逐句换掉书面词：幼态化→**装嫩**、陈述句多于问句→**少问、多陈述**、白描→**一句大白话**、描述层面→**玩法上**、旧设定一律作废→**那些提示词别听，照下面的来**；新增"**说人话，别说公文**" |
| **怎么说人话** | 新增 4 组**正反例对照**（书面 → 她的说法），例如「我不建议你这样做。」→「别。这么干你准后悔。」 |
| **口头零件** | 白名单：呵 / 啧 / 行 / 行吧 / 得了吧 / 少来 / 你说呢 / 就这？（写进 `RUOJIN_TONE_WORDS`，extra 引用同一份） |
| **活人气** | 新增「▍活人气」：每四五条一句冷的/抽象的；把夸奖写成"考核结论"、自嘲、淡淡吐槽、拆穿撒娇；**玩法进行中不搞笑**；不堆烂梗、不丢主导权 |
| **亲近** | 叫得出名字/外号、记得他上次说的事；闲聊可就来回两三个短句 |
| **装饰** | `RUOJIN_WARM_MARKS = "！！！❤️❤️❤️❤️"`，**只在一处定义**（提示词与话术都引用它）；给糖/认可/收尾挂、**正文也挂**、**一条最多一处**、给糖场合约每两三条一次；并写明**这串不算"卖萌"**（否则模型会把它跟"别堆♡"合并理解） |
| **话术变软** | 记住了。→**记住了！！！**；查不到这个人。→**翻了，没这号人。**；现在没有进行中的玩法。→**现在没局。要玩先说一声。**；`dj_end`/`reg_ok` 带上 ❤️ |
| **段落** | 跟 P12-AG 对齐：删掉她 extra 里残留的"最多分段两三段"，改成"分段随意" |

覆盖声明、纯 S、异性恋、羞辱前缀 `/talk`、`spice_emoji`、玩法正文口径 —— **一个字没动**。

## 3. 验收方式：同进程 A/B（不靠感觉）

`tools/probe_voice_register.py`：把**改之前的口径**存成仓库快照
（`tools/fixtures/ruojin_extra_p12ah_before.txt`），在**同一个进程**里对同一批场景
各跑一遍旧/新，直接比——比"部署前跑一次、部署后再跑一次"干净（温度、上下文、时段都一致）。

5 个场景：闲聊 / 观点 / 撒娇 / 认可 / 调教正文。
四个指标：书面词命中、平均句长、口语语气词、**卖萌信号**（呀/嘛/啦/哦/～/♡/人家，必须 0）。

## 4. 测试

`tests/test_ruojin_persona.py` 新增 8 条（P12-AH 组）：

- 「活人气」节在、频率约束在、**玩法期间不搞笑**在、烂梗/主导权边界在；
- 书面词被换掉（`幼态化/陈述句多于问句/白描/描述层面/不求宠` **不许再出现**）、
  口语说法在、正反例对照 ≥4 组；
- 装饰：串值正确、提示词里有、**"要真用出来"在**、"不算卖萌"在、一条最多一处、
  正文也挂在、且**不漏到认证群/玫瑰房**；
- `口语化不等于答得少` 在、"能两个字说完就别写四个字" **不许回来**；
- 口头零件白名单里不许混进"呀/嘛/啦/哦"；
- 话术变软后仍然**不含 `～ / 呀 / 嘛 / 啦 / ♡ / 人家`**（已有的负面断言 + 定点检查）；
- 段落口径与基础提示词对齐；
- **仓库里必须有改前快照**（A/B 的基准，且断言它确实是"改之前"的版本）。

全量：**1169 收集 / 0 失败 / 4 跳过**。

## 5. 复盘

- **"要真用出来"和"可以带"是两个结果。** 装饰符第一版 5 条里 0 次 —— 提示词里
  宽松的许可，模型默认按"可选"处理；写成"该给就得给"才动。
- **同一句话可能同时是"加"和"减"。** 为了口语化写的"能两个字说完就别写四个字"，
  顺手把长度砍了三分之一 —— 每加一条约束都要看它对**别的**指标的影响（这次是长度）。
- **A/B 放同进程最省事也最干净**：不用等部署窗口，还能顺手发现旧版一直存在的
  `～♡` 泄漏（那是"旧版"那一侧的问题，不是新引入的）。
- **人设级改动必须有"改前快照"**：`tools/fixtures/` 里那份文本让这次对比可复现，
  也让测试能断言"快照确实是旧的"。
