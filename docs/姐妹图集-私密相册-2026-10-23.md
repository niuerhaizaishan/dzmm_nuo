# 姐妹图集 · 私密相册（2026-10-23）

## 需求与结论

需求：姐妹图集增加一个私密相册，**只有妹子群的成员可以操作和查看**。

结论：私密相册作为第五个分区 `私密相册` 上线。查看与操作都要求「当前妹子认证群成员」身份，由 `chatroom.getMembers` 实时复核，不使用历史名单；公开分区原有规则不变（所有人可看、可保存原图，成员可上传/改名/移动/删除）。后端（A 实例指令层 + `dzmm-gallery` 网页 API）已部署；网页前端源码与自包含单文件包已产出，仍需在 Gamefy Workbench 手动上传发布（见「待办」）。

## 权限模型

| 能力 | 公开四区 | 私密相册 |
| --- | --- | --- |
| 列表 | 所有人（`GET /api/gallery/items`） | 仅成员（`GET /api/gallery/private-items`） |
| 原图 / 预览 | 所有人（`GET /api/gallery/images/{id}`） | 仅成员（`GET /api/gallery/private-images/{id}`） |
| 上传 / 改名 / 移动 / 删除 | 仅成员 | 仅成员 |
| 收藏 | 登录玩家（按身份隔离） | 仅成员 |

不泄露编号存在性：公开列表永不返回私密图片；公开原图路由对私密编号一律 404；收藏接口对私密图片、已删除图片、不存在的编号统一 404，不能靠状态码探测。

实现落在三处：

- `runtime/gallery.py`：`PRIVATE_CATEGORY` / `ALL_CATEGORIES`；`Store.list(uid, only_private=…, include_private=…)`、`Store.image(…, include_private=…)`、新增 `Store.exists(…)`；`save`/`move` 接受私密分区；`/保存 私密相册`、`/移动图片 编号 私密相册` 与网页端等价；`/漫画` 介绍文案说明公开与私密的分界。
- `runtime/gallery_api.py`：新增 `GET /api/gallery/private-items`、`GET /api/gallery/private-images/{image_id}`，两者在中间件里强制 Bearer + 成员复核；`/api/gallery/me` 增加 `can_view_private`；收藏接口补成员门禁；`gamefy-comic/publish` 缺失时不再挂静态路由（生产镜像只跑 API 也不会启动失败）。
- `gamefy-comic/publish/`：第五个分区标签、上传分区、移动目标均带 `data-private`，仅在 `can_view_private` 为真时显示；私密图片的缩略图与原图走成员路由；手机窄屏分区名显示为「私密」，窄屏分区导航由固定四列改为 `auto-fit`，第五个分区不挤行。

同一张图允许在公开分区与私密相册各存一份：去重按「分区 + 摘要」，互不影响。
