## 一、一句话

## 二、怎么玩（群里）

| 你想做的 | 发什么 | 会发生什么 |
| --- | --- | --- |
| 起一局 | `/调教 糯糯 学狗叫` | 「🔗 调教开始。目标：糯糯。」+ 我下的第一条命令 + 参与方式提醒 |
| 不给命令也行 | `/调教 糯糯` | 我按你和目标的性癖**自编**一条 |
| 接话 / 换命令 | `/命令 跪好`、或直接 `/跪好` | 目标之外的群友（以及目标本人）都能发；每轮目标 +20 发情值 |
| 目标回应后 | —— | 我催一句"下一条命令谁发"；**30 秒没人发我就自己接一条**（`diaojiao_idle`） |
| 收尾 | `/调教结束`（或 `/结束`、`/停止`） | 我出收尾小结 |
| 不管它 | —— | **5 分钟没动静自动收尾**（不会永久卡住这个群） |

> ⚠️ 一个副作用（提前说清）：`调教` 在代码里**还兼着"没认出来的斜杠指令"的兜底**。
> 所以群里如果有人发 `/talk妈妈` 这类**别的 bot 的指令**，若瑾会回一句
> 「现在没有进行中的调教。」（以前是静默吞掉）。觉得吵我可以改成"没在局里就不理"。

## 三、这次动了什么

1. **打开开关**（走配置页的同一条校验路径 `config_store.save`，自动备份）：
   `上班群 features.diaojiao = true`、`features.diaojiao_idle = true`。
   热加载 1 秒生效，**不用重启**：

   ```
   16:12:27 P12: 热加载 功能 · f4ec4c21…|diaojiao : 关 → 开
   16:12:27 P12: 热加载 功能 · f4ec4c21…|diaojiao_idle : 关 → 开
   ```
2. **文案搬进话术表**（`runtime/diaojiao.py` 里原来写死的 6 句 + 参与提醒）：
   新增 7 个 key —— `dj_format` / `dj_no_target` / `dj_start` / `dj_timeout` /
   `dj_replied` / `dj_idle` / `dj_hint`。
   - **默认那份逐字等于原来的字面量** ⇒ 认证群一个字没变；
   - 若瑾那份是命令句 ⇒ 不会漏出软萌口吻；
   - 玫瑰房那份按管家口径（不撒娇、不叫客人姐姐/妹妹）。
3. 若瑾的 `/说明` 里补上调教条目与收尾方式。

## 四、若瑾会说的调教文案（线上自检实拍）

```
dj_format    格式：/调教 点名 命令。例如 /调教 糯糯 学狗叫。
dj_no_target 没这个人。换一个。
dj_start     🔗 调教开始。目标：糯糯。
dj_timeout   ⏱️ 调教结束（五分钟没人动）。
dj_replied   他应了。下一条命令谁发——/命令 xxx，或直接 /xxx，他自己也能发。三十秒没人我自己来。
dj_idle      三十秒没人发命令。我接着来。
dj_hint      想接话的跟着发：/命令 xxx，或直接 /xxx。三十秒没人我继续。
```
对照：认证群仍是「🔗 调教开始！目标：某某～」「想参与的姐妹也来玩呀～…」（原样）。

## 五、可调项

| 想改的 | 在哪 | 说明 |
| --- | --- | --- |
| 无动静多久自动收尾 | 参数 `diaojiao.timeout`（默认 300 秒） | 页面上按群可调 |
| 冷场多久自编一条 | 参数 `diaojiao.idle_seconds`（默认 30 秒） | 只在"等命令"阶段 |
| 被调教一轮加多少发情值 | 参数 `heat.diaojiao_round`（默认 20） | 发情值系统 |
| 关掉冷场自续（不再自动接话） | 群里功能面板：`调教冷场自续` | 热加载 1 秒 |
| 整个调教关掉 | 群里功能面板：`调教` | 关掉时会把进行中的调教状态一起复位（不会把群弄哑） |
