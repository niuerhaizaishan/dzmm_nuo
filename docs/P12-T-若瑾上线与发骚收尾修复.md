## 三、逐项说明

### 1. 若瑾这个人设（P12-T ①）

- **口径**：参考小小糯的人设，名字改「若瑾」，**纯 S 属性、异性恋**，功能先只开发骚与羞辱。
- **做法**：`personas.py` 里新增 `PERSONAS["ruojin"]` + 一整组 S 口吻话术（`RUOJIN_PHRASES`）。
  人设里显式声明了"覆盖章节"：作废源人设里所有"妹妹/姐姐/被调教"的段落，
  改成"男女一视同仁、拉到最满"，避免底层提示词把 S 拉回 M。
- **取向字段**：`orientation="straight"` 现在**只**用来决定"要不要走最狠那条规则"，
  不再限制玩法对象（你后来定的口径）。
- 文件：`personas.py`、`bots`/群配置、`docker-compose.prod.yml`（`DZMM_BOT_TOKEN_RUOJIN` /
  `DZMM_BOT_SECRET_RUOJIN` 透传）

### 2. 先识别性别，再分路生成（P12-T ②）

- **需求**：原来只按"档案里有没有写性别"判断，群里 55 个人的档案都没写 → 一律走默认那条。
- **做法**：新增 `runtime/members._gender_of(uid, cid)`：**先查档案**，档案没有就**查一次平台**
  （`getChatroomUser`），查到**写回档案**（下次零成本）。羞辱指令在生成前先跑这一步。
- **效果**：实测「工具熊 Jr.」被判为**女生**并回写档案；群内其余 55 人也被补齐。
- 文件：`runtime/members.py`（`_gender_of`）、`bot.py`（羞辱分支先取性别）

### 3. 羞辱「工具熊」加 `/talk` 前缀（P12-T ③）

- **需求**：你要求"在羞辱工具熊的时候，要在**最最前面**加上 `/talk`"。
- **做法**：话术层配两个键 `insult_prefix_who = 工具熊` / `insult_prefix_text = /talk`，
  命中昵称子串就给消息加前缀，并且**跳过自动的 `🤖` 前缀**（否则 `/talk` 就不在最前面了）。
- ⚠️ **靠昵称匹配**：工具熊改名（去掉"工具熊"三个字）前缀就失效；想更稳可以改成按 uid 认，
  说一声我就改。
- 文件：`bot.py::_insult_prefix`、`personas.py`（话术键）

### 5. 修「发骚怎么结束没反应了」（P12-T ⑤，真 bug）

- **现象**：若瑾那个群里，发骚进行中发 `/结束`，日志是

  ```
  🔇 [f4ec4c21] 功能已关闭，静默: /结束
  ```

  发骚根本轮不到收尾。
- **根因**：判断"这条命令是不是属于被关掉的功能"时，**只看第一个匹配的归属**。
  `/结束` 这个词同时被 **骰子 / 公演 / 剧情 / 投票 / 发骚收尾 / 调教** 六支认领，
  表里第一项是骰子；骰子在这个群是关的 → 直接判静默，后面"发骚收尾开着"根本没看。
- **修法**：归属表每一项补一个**闸门**（`gate(cid, cmd)`）——"分派链里那一支**此刻**会不会接手"：

  | 分支 | 闸门（什么时候才算它在等这条命令） |
  | --- | --- |
  | 骰子 | 开局/看局/叫数类不用等；`/退出` `/结束` `/下一轮` 要**骰子局在进行** |
  | 公演 / 剧情 / 投票 / 发骚 | 各自**正在进行中** |

  判定变成：按分派链顺序找**第一支真会接手**的 → 它开着就放行，它关着才静默；
  一支都不接手 → 交回兜底聊天（与以前一致）。
  于是"关掉骰子"不再把"没有骰子局时的 `/结束`"当成静默理由 —— 骰子那支**本来就没在等**这条命令。
- **连带修正**：`/发骚结束` 的归属从「收尾+发起」共用一项，拆成两项 ——
  **有进行中的发骚时**收尾被关就该静默，不能落空变成"对『结束』这个人发起一次场景"。
- **线上证据**（容器内真配置探针 `tools/verify_fasao_end.py`）：

  ```
  该群开关：scene 开 / scene_end 开 / dice 关 / diaojiao 关 / vote 关 / story 关
  没有进行中的发骚 → 静默 = True    （期望：没人接手，别当闲聊回）
  发骚进行中       → 静默 = False   （期望：放行给 end_fasao）
  派发链条件：is_fasao_end_cmd=True / active=True / scene_end=True ⇒ 会进 end_fasao
  end_fasao 返回 = '🎲 到这里。'     （有正文 ⇒ 群里看到 💬，不再 🔇）
  ```
- **群里怎么验**：在若瑾那个群起一次发骚，然后发 `/结束`（或 `/停止`）——
  应该看到收尾话术，日志里是 `💬` 而不是 `🔇 … 静默`。
- 文件：`bot.py::_cmd_owned_by_disabled` + `_CMD_FEATURE_ORDER`（新增 5 个闸门函数）、
  `tests/test_feature_registry.py`
