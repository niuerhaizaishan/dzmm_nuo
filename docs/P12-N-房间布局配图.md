## 2. 两条触发路径

| 路径 | 位置 | 行为 |
| --- | --- | --- |
| 改布局 | 房间消息分支回复成功之后 | `_room_layout.maybe_send(sender, cid, r_text, r_uid)` → 发对应图 |
| 屋子复原 | 女鬼剧本结束、屋主回来（`ROOM_GHOST_BACK`） | `_layout_after = DEFAULT_LAYOUT` → 发**玫瑰房**那张 |

口径（刻意保守）：

1. **只有屋主**（`_room_owner`）的改布局话才发图 —— 客人说"改成泳池"由 AI 婉拒，不发图；
2. **必须点名**（屋主 2026-09-27 补定："我觉得还是前面必须加薇丝才好吧"）：`@薇丝` 或说出"薇丝"
   才算命令。所以光说「泳池」「改成泳池」**不认**（管家不应声、房间也不变），
   而「薇丝 泳池」「@薇丝 改成泳池」认；
3. **认不出的风格不发图**（"赛博朋克" → 什么都不发）：宁可不发，也不发一张不相干的房间；
4. **光报布局名也算**（`_bare_layout`：去掉称呼与标点后整句正好是布局名或其关键词，
   允许尾巴带 风格/房间/模式/吧/呢/呀），但同样要先点名；
   "薇丝 我想去泳池""薇丝 泳池真好看"这类**不算**（不是整句报名字）；
5. 同一种布局 120 秒内只发一张（`bot_photo` 的去重表，与自我介绍立绘共用）。

实现要点：判定拆成可测纯函数（`layout_of` / `is_layout_cmd` / `photo_url`），
发送统一走 `runtime/bot_photo.py`（官方 Bot 通道、**绝不抛异常**、带短去重）。

## 3. 事故与加固（同一次上线）

第一次部署（12:03）**只上传了 42 个文件**（正常 145）：那次部署与全量 pytest **并发**跑，
`Get-ChildItem` 中途报错被 `-ErrorAction SilentlyContinue` 吞掉。后果是**生产半更新**
（`bot.py` 还是旧的、两个新模块没上去），而日志只写 `packed 42 files`，看着像成功。

**加固**（`deploy.ps1::Push-CodeFiles`）：

- 上传前校验清单：必须含 `bot.py` / `brains.py` / `runtime/obs.py` / `runtime/prompts.py`，
  `prompts/*.md ≥ 30`，总文件数 `≥ 100`；不满足就 **throw（什么都没上传）**；
- 部署**不要与全量 pytest 并发跑**（这是事故的直接诱因）。

另一个坑：**`deploy.ps1` 里不能写非 ASCII**。中文字符串字面量在这台机器上会被按 GBK
解码，直接触发 PowerShell 解析错误（注释里的中文也一并改成了英文）。现在该文件是纯 ASCII。
