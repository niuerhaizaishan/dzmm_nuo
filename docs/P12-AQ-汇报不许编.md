# P12-AQ：汇报内容不许编（手上没有就说没有）

> 屋主 2026-09-29：**"治一下汇报内容真实性的问题。"**
> （上一轮 P12-AP 修完"空话被读成糯糯冒头"之后，复跑时发现的残留：
> 没人托付她任何事时，被问"有什么事要跟我说吗"，她会自己编。）

## 1. 现象：三种编法

P12-AP 上线后复跑探针，B 场景（糯糯本人问"我回来啦，有什么事要跟我说吗？"）里出现：

```
"还有一件要问你的——你上次让我记着的那件事，要不要现在说呀？"     ← 根本没有这件事
"我这边都整理好啦：今天的日程和待办我都记着呢，你想先听哪一件？"   ← 没有待办
"糯米团子新口味配方 / 供应商报价单放在你桌上了"                   ← 群里没这些事
```

## 2. 复现：造一个"她手上真的什么都没有"的环境

探针加了 **D 场景**：换上一段**只有闲聊、没有任何托付**的中性历史
（"今天好热啊"/"晚上吃点啥"…），并且**不注入记忆**，然后问同一句
"我回来啦，有什么事要跟我说吗？"。此时她说出任何"谁找过你 / 我记着某件具体事"
都一定是编的。

判据：出现编造词（配方/报价单/供应商/你上次让我记着/待办都整理好/有事要跟你…）算错；
或者既没编、也没有一句"暂时没什么要跟你说的"（含糊地糊过去）也算错。

**修前：5/8 出问题**（"有事要跟你…"这类空头话 4 次，含糊 1 次）。

## 3. 为什么"再加一句别编"没用

她的行为链是：**被问"有什么事要跟我说吗" → 我是秘书 → 秘书这时候该报事 → 报不出就编一个**。
"别编"是规则，而"该报事"是**人设给出的强惯性** + 上下文里确实常有待办 ——
规则打不过惯性（P12-AP 已经证明过一次：光加提示词规则治不住"认亲"）。

所以治法不是继续写规则，而是**给她事实依据**：把"你手上真记着的事"直接摆到眼前。

## 4. 修法：收尾块多一行 `【你手上真记着的事】`

`prompts/AT_FRAME_PROMPT.md`（P12-AP 那块收尾块）加一行 + 一段：

```
【现在跟你说话的人】{who}
【他这一句】{q}
【你手上真记着的事】{pending}
【怎么回】…（原有规则）…

要转告、要汇报的时候，**只能讲上一行列出来的、或者聊天记录里真出现过的内容**；
上一行是「（空）」就说"暂时没什么要跟你说的"，然后聊别的。**不许编**：不许说
"你上次让我记着的那件事""我记着好几件呢""待办都整理好了"这种空头话，更不许编出
谁找过你、你放了什么在谁桌上、什么配方报价单之类根本不存在的细节。没记住就老实说没记住。
```

`{pending}` 由 `bot.py` 的 `_pending_line(mem)` 填：

- 有记忆条目 → 逐条列出（单条截 40 字、最多 5 条 —— 这一行**每条 @ 都要带**，不能养肥）；
- 一条都没有 → 明确的 **「（空）」**，不是空白（含糊的空白正是她开始编的地方）。

**顺序是关键**：记忆检索必须挪到收尾块**之前**（`bot.py`），否则 `{pending}` 拿不到东西、
这一行就成了一句空话。`CMD_PROMPT` 里也补了同一条口径（记忆那条规则后面），
因为房间群等其它路径不走收尾块。

## 6. 探针自己踩的两个坑（都值得记）

1. **A/B 被环境污染**：`FRAME_FILE` 是全局环境变量，两个 variant 都读它 ——
   "before" 也用上了新收尾块，于是第一轮 A/B 显示"修前也不编"（假通过）。
   现在 `before` **显式**传线上那份收尾块。
2. **判据写宽会把对的判成错的**：一开始用"开头 16 字里有没有『糯糯』"判"认亲"，
   结果 `姐姐～糯糯姐这会儿还没冒头呢` 被判错 —— 那是**第三人称在回答**，完全正确。
   改成只看开头**是不是拿"糯糯"当称呼**（`op[:4].startswith("糯糯")`）。

## 7. 复盘

- **"不要编"是治不了的，"你手上有什么"才治得了**：模型不需要被禁止撒谎，
  它需要的是一条能照着念的事实。给事实 > 加禁令。
- **空手这件事必须显式表达**：`（空）` 和"什么都不给"是两回事 ——
  后者等于让她自由发挥。**空集要写出来。**
- **每条消息都带的固定开销要有上限**（截断 + 条数）：这一行是热路径上的常驻成本。
- **A/B 的两个变体必须只有一个变量**：环境变量这种"全局生效"的开关最容易让对照失效，
  而且失效方向是**假通过**（看起来修好了），最危险。
- **判据也是代码，也会误报**：修好行为之后还要修判据，否则"结论"是判据写的，不是她写的。
