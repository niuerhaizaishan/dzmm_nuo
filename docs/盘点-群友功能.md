## 0. 先说三个"全局门控"，后面表格大量引用

| 门控 | 定义位置 | 语义 |
|---|---|---|
| `GROUPS` | `bot.py:80`（默认值 `bot.py:16-22`） | 主循环逐群处理；不在表里的群完全不可见 |
| `MUTE_CIDS` | `bot.py:81`（默认 `bot.py:25` 空集） | **只推进 `last_id`、不做任何处理**：不回、不筛查、不欢迎、不推送、不同步档案 `bot.py:2118-2122` |
| `SCREEN_CIDS` | `bot.py:82`（默认 `bot.py:28-32`） | 入群筛查（踢游客/踢男/认证群文案）`bot.py:2162` |
| `PUSH_CIDS` | `bot.py:83`（默认 `bot.py:34-37`） | 定时问候 / 记忆汇报 / 12·18 点排行 `bot.py:1706,1728,2775` |

| `TREND_CIDS` / `RECAP_CIDS` | `trend.py:25` / `recap.py:24` | 都等于 `{PRIMARY_CID}`，即 `bd7fe6a4-…`（`ctx.py:23`） |
| `OWNER_UID` | `perf.py:39` = `a56cbd67-…`（糯糯） | 代注册 / 同步 / 公演审核 |
| `VV_UID` / `NUONUO_UID` | `personas.py:99-100` | 玫瑰房屋主 / 半个主人 |
| 群状态字典开关 `state[cid]` | `devil_enabled` `bot.py:2397`；其余见 §2 | 唯一"存在群状态里"的功能级开关就是它 |

配置来源：`config_store.load()` `bot.py:68-78` → 文件不存在时**逐字退回**上述代码默认值（`config_store.py:312-336`）。
⚠️ 注意：`config.json` 里每个群的 `persona` 字段**运行期完全不被消费**——人设只由 `personas.CID_PERSONA`（源自 `ROOMS`）决定（`personas.py:115,235-238`；`bot.py` 全文无 `group_specs`/`GroupSpec.persona` 读点）。它只影响启动校验与运维后台表单。
`GroupSpec.enabled=False` 会把群移出 `GROUPS`（`config_store.py:231-232`）——这是**唯一真正的"整群关停"**。
