# P12-L：薇丝的自我介绍配图（只发图，不带字）

> 起因：2026-09-27 屋主给了一张黑猫管家的立绘，要求"在 rose 房薇丝自我介绍之后发送这张图片"，
> 并补充口径：**两处都发**（进房问好 + `/自我介绍` 指令），"**也不一定是指令，比如问薇丝你是谁
> 的时候也发**"。配图不带文字。

## 1. 三条触发路径（都在 `bot.py` 里接线）

| 路径 | 挂点 | 调用 | 日志 |
| --- | --- | --- | --- |
| `/自我介绍`・`/介绍`・`/你是谁`・`/whoami` | 命令回复发送成功后（`is_intro_cmd(cmd)`） | `_intro_photo.send(reason="指令")` | `🖼️ [cid] 自我介绍配图已发（指令）` |
| 新客进房、管家问好之后 | `room_welcome` 分支，问候发完 | `_intro_photo.send(reason="进房问好")` | `…（进房问好）` |
| 群里自然语言问"你是谁" | 房间消息回复发送成功后 | `_intro_photo.maybe_send(r_text, reason="自然语言")` | `…（自然语言）` |
| 被 @ 的提问里问"你是谁" | @ 分支回复发送成功后 | `_intro_photo.maybe_send(q, reason="@提问")` | `…（@提问）` |

**顺序**：文字先发、图紧跟其后（挂在 `sender.send(reply, cid)` 成功之后，`ok` 才补图）。

## 2. 图片放哪儿（关键约束）

官方 Bot API **只能发 URL 图片**（`POST /api/bot/bot<token>/sendPhoto`，没有 multipart），
所以图必须公网可访问。做法是把它挂在自家域名上：

- 文件：服务器 `/opt/dzmm/deploy/img/weisi.png`（仓库里也留了一份 `deploy/img/weisi.png`）
- Caddy：`handle_path /img/* { root * /srv/img; file_server }`，容器挂
  `-v /opt/dzmm/deploy/img:/srv/img:ro`（见 `deploy/Caddyfile`、`deploy/start_caddy.sh`）
- 地址：`https://www.nuonuo.pw/img/weisi.png`
- 实测：公网 `200`、`1534303` 字节、md5 `a8dfc52f88a8e6f750a218ce5bddab0e`（与本地一致）；
  `/nothing` 仍 `404`、`/bot/webhook` 无 Secret 仍 `401` —— 加路径没有放宽别的口子。

**换图 = 换同名文件**（不用改配置、不用重启）：

```powershell
scp -o BatchMode=yes -o Ciphers=aes128-gcm@openssh.com `
    deploy\img\weisi.png root@47.237.152.187:/opt/dzmm/deploy/img/weisi.png
# 校验：curl -s https://www.nuonuo.pw/img/weisi.png | md5sum
```

## 3. 开关 = 话术本身

配图 URL 存在**话术**表里（`personas.PHRASES`，人设页可改）：

| 人设 | `intro_photo` |
| --- | --- |
| `nuo`（默认/认证群） | `None` → **不发图** |
| `rose_butler`（玫瑰房） | `https://www.nuonuo.pw/img/weisi.png` |

于是"关掉配图"不需要新增功能开关：**把人设页那一行 URL 清空**即可（热加载，约 1 秒生效）。
想换成别的图（比如以后发到平台图床），直接把 URL 换掉。

## 4. 三条纪律（都写了测试）

1. **意图判定要窄**：`你是谁`・`你叫什么`・`介绍一下你自己`・`你是干什么的`… 命中；
   `你是什么意思`・`摘玫瑰`・`今天天气不错` 不命中；带管家名字时（`薇丝是谁`）要求句子更短。
   超长句（>60 字）不认 —— 免得有人长篇大论里夹一句"你是谁"就蹦图。
2. **绝不把主循环带崩**：没有 URL（认证群）/ 没有 Bot 通道 / 平台报错 → 只返回 `False` + 一行日志。
   这条挂在**每条回复**后面，抛异常会毁掉整个消息处理。
3. **同一条消息只发一张**：同一条消息可能被 @ 分支与房间分支各看到一次
   （`bot.py` 的 `_leftover` 放回逻辑），所以 `maybe_send` 带 120 秒的 `(cid, 原文)` 去重窗口。

**为什么只走官方 Bot、不走账号侧车**：房间群里说话的是**薇丝-bot**，若用侧车账号发图，
图片会以另一个身份（小小糯～）出现，人设当场穿帮。

## 5. 测试

`tests/test_intro_photo.py`（29 条）：

- 取值：只有玫瑰房有 URL，认证群/未知群为空；话术已登记且补了中文标签；`health()` 干净
- 意图：9 个命中样本 + 7 个不命中样本（含"你是什么意思"与超长句）
- 发送：走 `bot_for(cid)` → `send_photo_url`；无 URL / 无通道 / 平台拒绝都只返回 `False`
- 去重：同一条只发一张、换问法照发
- 官方通道：URL 形状（`/api/bot/bot<token>/sendPhoto`）、payload、caption 可选、
  两类失败（`rejected` 可重发 / `ambiguous` 绝不重发）、空 URL 直接拒
- 接线：`bot.py` 里四个挂点一个都不能少
