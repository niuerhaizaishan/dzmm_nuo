## 一、工作群里 `/talk`、`/ask` 没在局里就不理 ✅

**原来**：`/talk`、`/ask` 这类**别的 bot 的指令语法**会被当成"调教命令"，
没在局里时回一句「这个我不会……」（认证群）/「（把茶杯搁下）这个我不会……」（工作群）。

**现在（工作群）**：没在局里 ⇒ **完全不回**。
`/命令 xxx` 是我们自己的参与语法，仍旧回"现在没有进行中的调教。"（给个明确提示）。

**实现**：新增话术 `dj_idle_unknown` —— **留空 = 明确不理**。
- 工作群（若瑾那份）：留空 ⇒ 静默；
- 认证妹子群：**没写过这个 key** ⇒ 仍旧回 unknown_cmd，行为一个字不变。

> 关键点：代码要能区分"**明确写成空**"和"**没写过、回落默认**"这两件事 ——
> 新增了 `personas.phrase_is_blank()` 就是干这个的（配置页里把这条清空也能触发静默）。

线上自检（真配置）：
```
工作群：  phrase_is_blank=True   /talk xxx → ''（静默）   /命令 xxx → 现在没有进行中的调教。
认证群：  phrase_is_blank=False  /talk xxx → 咦？这个指令小小糯还不会呢～…（原样）
```

## 二、发骚 / 羞辱正文撒表情（💗💦🥵）✅

工作群与妹子群都开；**玫瑰房明确关掉**（保持管家口吻）。

**做法**：话术 `spice_emoji`（**空格分隔**的表情清单，留空 = 不撒），
代码只负责"撒在哪、撒几个"：

- 只在**句末标点之后**插（。！？～…），绝不插在句子中间；
- **优先插在行尾/段末** —— 段中来个「？💗下一句」很怪；
- 数量 = min(6, 句末标点数 ÷ 2)，在候选点里**均匀取点**（长文的表情是散开的）；
- 标题行（`🎲 组合`）不碰；
- 接线五处：羞辱、羞辱续写、发骚（`/发骚`）、发骚续写、重写。

线上自检（真跑模型）：
```
[工作群·羞辱] 315 字 / 4 个表情
[工作群·发骚] 整条 924 字（正文 904）/ 6 个表情；标题行 0 个
[认证群·羞辱] 249 字 / 3 个表情
```

想换一组表情（比如加 🖤、⛓️）：人设页把 `spice_emoji` 改成 `💗 💦 🖤` 这样即可，1 秒生效。
不想要表情：清空那一行。
