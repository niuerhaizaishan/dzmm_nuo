# DZMM 小小糯 Bot 更新总结（2026-08-22）

## 一、消息收发方式（重大改造）

### 1. 读消息：HTTP 轮询 → Socket.IO 订阅

- **根因**：必须 `polling transport + syncMode=http` query，纯 websocket 会「连接成功但服务端不推消息」
- `sio_subscribe.py`：`polling+syncMode=http`（query 在 url 不在 socketio_path）、`wait=False` + `reconnection=False` + 手动重连循环、namespace timeout 10s
- 主循环：`drain(cid)` 优先（内存操作无退避，固定 `FAST_INTERVAL` 0.8s）+ `need_resync` 断线补拉 + HTTP 每 10 分钟对账
- self-echo 跳过 `sent_by == NUO_UID`

### 2. 发送提速：常驻群 fast path + insert_text

- `PRIMARY_CID`（妹子认证群）预加载常驻，不 goto 整页重载
- `insert_text` 替代逐字符 `type`（行间 Shift+Enter 换行）：200 字 ~0.001s vs type ~0.5s
- 延迟大头定性：切群 `goto` 整页重载 2.9~3.6s，不是字数也不是 SIO 链路（<0.4s）
- 效果：妹子认证群发送约 1~2s（原 `/发骚` 全链路 ~6.4s）

### 3. 发送失败兜底：DZMMSocket

- Playwright 失败重试 2 次后，降级 `_fallback_send` → DZMMSocket HTTP 快速发送
- importlib 以独立模块名 `dzmm_socketio` 加载项目自己的 `socketio.py`（避开 python-socketio 的模块名冲突，不污染 `sys.modules`）

### 4. 去 headless 指纹

- `launch_persistent_context` 加 `--disable-blink-features=AutomationControlled` + 真实 Chrome UA
- 修复后 `webdriver=False`、无 HeadlessChrome（命中 PostHog 检测的黑名单已清除）

### 5. 告警 / 熔断

- `wx_alert.py` 直连 iLink 微信告警；captcha/unauthorized 事件告警
- 连续 3 次失败熔断退出；两个轮询 cronjob（健康监控/公演审核）已删，改为事件驱动

## 二、发骚 / 羞辱 / 查人 功能优化

### 1. 发骚 / 继续：上下文增强 + 第三人称强化

| 改动 | 文件 | 说明 |
|------|------|------|
| 发骚第一段注入主角资料 | `bot.py` `scene()` | 注入签名/简介/画像（各截 150 字），**仅非自定义时**注入（自定义玩法只润色不加料） |
| 继续指令历史窗口扩大 | `brains.py` `generate_scene_continue` | `history[-3:]` → `history[-5:]` |
| 第三人称强化 | `brains.py` 三个 prompt | 「整篇第三人称，用主角名字（可去括号）或"她/他"指代，绝对不要第一人称"我"」 |

### 2. 羞辱 / 查人：随机化去套路

| 功能 | 随机池 | 篇幅 | 关键约束 |
|------|--------|------|----------|
| 羞辱 | 5 种风格：恶魔毒舌 / 阴阳怪气 / 优雅羞辱 / 色气挑逗 / 记仇翻旧账 | 6-8 句，150-250 字 | 每种风格强制「露骨直白、语言淫荡」底色 |
| 查某人 | 4 种角度：客观档案 / 锐评式 / 段子式 / 反差揭露 | 未注册 250-300 字，已注册 250-350 字 | 随机角度切入，内容充实 |

- 随机由 Python `random.choice` 注入前定好（不让 LLM 自选）
- **`/继续` 羞辱不随机**：沿用上一段风格，避免中途变调

## 三、探讨结论（未改代码，仅存档）

1. **captcha vs Chrome 正常**：bot 和 Chrome 走同一机场 IP（系统代理 7890），captcha 是「IP + 行为/指纹」综合判断；机场共享 IP 本身是 captcha 高危因素
2. **bot 能否走真实 IP**：不能走本机真实 IP（dzmm.ai 国内直连 HTTP 000 被墙），方向是独享干净 IP
3. **自建 VPS 方案**：已存档 `docs/自建VPS独享IP步骤.md`（五步：买 VPS → 搭 3x-ui → FlClash 接入 → 验证 → 固定，bot 代码零改动）
