## 三、逐项说明

### 1. 星象卡五段式（P12-K）

- **需求**：你给了一张星座运势模板图，要求玫瑰房照这个格式来；定稿口径 = 保留分数与宜忌，接五段，末尾三件套。
- **做法**：分数/宜忌是我们的确定性数据（哈希算的，同人同日同座必相同）；五段由 AI 一次写完
  （新提示词强制输出五个【】标签）；末尾的**幸运数字/速配星座**新增为确定性数据（速配是十二星座三选一）。
- **安全网**：AI 万一不按格式写，会自动退回"分数 + 一段点评"，**绝不会发出半张卡**。
  实测模型很听话（5 行 / 304 字）。
- **代价**：生成 1.25~1.77s → **2.38s**（多花 1 秒上下）。嫌慢就砍【综合运势】。
- 文件：`runtime/sign.py`、`brains.py`、`prompts/HOROSCOPE_PROMPT.md`、`personas.py`

### 2. 薇丝立绘 + 新自我介绍（P12-L / P12-Q）

- **需求**：①自我介绍之后发这张图 ②两处都发，问"你是谁"也发 ③简介开头换成你给的句子
  ④新人进群欢迎语、问"你是谁"都用新自我介绍。
- **做法**：官方 Bot API 只能发 **URL 图片**，所以图托管在自家域名
  `https://www.nuonuo.pw/img/weisi.png`（Caddy 新开的 `/img/*` 路径，**换图 = 换同名文件**）。
  触发点四个：`/自我介绍` 指令、进房问好、房间里的自然语言、被 @ 的提问。
- **开关就是话术本身**：人设页里 `intro_photo` 那行 URL 清空 = 不再发图（热加载 1 秒生效，不用重启）。
- 细节：你给的句子开头的 `🤖` 没写进文案（那是发送时自动加的，写进去会变两个）。

### 3. 修"薇丝一直说话"（P12-M，真 bug）

- **现象**：11:38 糯糯发了一条 @ 消息后，薇丝每 1~2 秒回一条，**连刷约 3 分钟**（52 次"放回队列"）。
- **原因**：一条 @ 消息同时命中 @ 分支与房间分支，@ 分支赢了之后，代码把**已经被处理的那条**
  也"放回队列"，下一轮捞回来的还是它 → 死循环。（你那句「重启服务」正好清空了内存队列，所以停了。）
- **修法**：被处理的那条绝不放回；再加一条兜底"同一条最多放回 3 次"。新增 8 条测试。
- **顺带**：这条路径在生产里此前从未触发过（`同批还有` 计数一直是 0），所以不是老问题复发。

### 4. 房间布局配图（P12-N）

- **需求**：改布局就发对应的图；玫瑰房是初始布局，恢复后自动是玫瑰房。
- **四张图**：审问室 `shenwenshi.jpg`、玫瑰泳池 `pool.jpg`、户外烧烤 `bbq.jpg`、玫瑰房 `rose.jpg`
  （都在 `https://www.nuonuo.pw/img/room/`）。
- **口径**（刻意保守）：只认**屋主**的命令；**认不出的风格不发图**（"改成赛博朋克"→ 什么图都不发），
  宁可不发也不发错房间；光说"玫瑰房"不算命令。
- **复原**：女鬼剧本结束、屋主回来 → 自动发玫瑰房那张。

### 5. 女鬼场景（P12-O + 补丁）

- **需求**：有人摘花触发女鬼、或者命令变成女鬼场景时发这张图；后来补一句"要进状态啊"。
- **做法**：命令路径与"男号摘花"**共用同一套状态与固定剧本** —— 女鬼上场（图）→ 管家不接话、
  门窗被带走 → 屋主回来 → 屋子复原 + 玫瑰房图。**链路闭环**。
- **口径**：只有屋主/糯糯能下这个命令；"女鬼真吓人"这类闲聊不触发；女鬼状态 3 小时超时兜底。
- **顺手修**：以前光说「变成女鬼」（不带"薇丝"两字）根本进不了房间分支，命令会石沉大海。

### 6. `/查` 开放 + 触发口径收紧（P12-P / P12-R）

- **`/查` 开放**：玫瑰房本来把客人的所有 `/` 指令都改成婉拒，`/查` 是"看档案"不是"吩咐管家做事"，
  所以单独放行（含 `/whois`、`/资料`）。
- **触发口径收紧**（依据是今天的真实数据：带"薇丝"/@ 的 11 条全部是有意叫她，误触发**全部**来自纯关键词）：

| 规则 | 结果 |

| ② 屋主的指令（改布局 / 女鬼） | 照旧不要求名字 |
| ③ 消息里 **@ 了别人** | 关键词规则一律不认（"@橘先生…摘个花试试"不再被当成摘花） |
| ④ 星座问答 | 保留自动，但**复读我们的卡片**不算（"速配星座：天蝎座"不再触发） |
| ⑤ 客人点单 | **必须点名**（"想喝一杯酒"这种闲聊不再触发） |

## 四、基础设施（你看不到但很关键）

1. **图片公网托管**：Caddy 新增 `/img/*`（容器挂 `/opt/dzmm/deploy/img`）。
   现在有 5 张：立绘 1 张 + 房间 4 张。**换图就是换同名文件**，不用改代码、不用重启。
2. **部署加固**（一次真实事故逼出来的）：
   - 事故：12:03 那次部署与全量测试**并发**跑，文件枚举被打断，**只上传了 42 个文件**（正常 147），
     生产变成"半更新"（bot.py 是旧的、新模块没上去），而日志只写 `packed 42 files`，看着像成功。
     **结果就是你 12:04 说的"屋子改成屋外烧烤"没图**。
   - 加固：部署前校验清单（关键文件在不在、prompts 齐不齐、总数够不够），不满足就**中止且什么都不上传**；
     图片也纳入上传白名单（换机器不会再漏图）。
   - 另一个坑：`deploy.ps1` 里不能写中文（这台机器会按 GBK 解码 → 直接语法错误），已改为纯 ASCII。
3. **运维工具**（都在 `tools/`，只读、不发消息）：冒烟回读（`watch_rose_card.py`）、
   实拍五段生成（`probe_sign_card.py`）、各批次上线自检脚本。
