## 施工记录模板（写新文档时照这个来）

```
# P12-XX：一句话说清要解决什么

> 屋主 YYYY-MM-DD："原话"

## 1. 现场（数据/日志，别只写感受）
## 2. 根因（为什么要改这里）
## 3. 改法（落点 + 为什么这样改）
## 4. 验证（单测/线上读数/A-B）
## 5. 不做什么（刻意留下的边界）
```

**两条纪律**：
1. 数字优先——"递话率 67%→20%"比"感觉更像人了"有用；
2. 写下**当时的判断依据**，包含"我原来想错了什么"（P12-BL 里那次 EBUSY 自伤就是最好的例子）。
