# 视频提示词引用原图

认证妹子群可以回复一张图片发送 `/提示词 视频 轻轻回头微笑`。模型结合图片中的主体、姿态、景别和构图，返回一段适合 Grok 图生视频的动态提示词；没有引用时继续按文字优化。继续生成视频时，需要再次回复原图发送 `/生视频 优化后的提示词`。

## 实现

- 使用原有 `gpt-6.1-sol` 与提示词服务配置，没有增加或变更密钥。
- 在后台任务中回查原始指令，核验消息 ID、发送者、群和指令内容，再按引用 ID 回查原图。支持实时推送缺少引用字段的情况，忽略引用预览内的图片地址。
- 通过既有 `GalleryPlatform` 读取平台 CDN 图片或此前生成图片的本地持久字节。引用失效、跨群、非图片或下载失败时结束任务并提示，不调用纯文字模型猜图。
- 支持 JPG、PNG、WebP 静态图片，原图上限沿用 10 MB、4000 万像素。校正 EXIF 方向，最长边缩至 1536 像素，透明背景合成白色后转为 JPEG，移除元数据，通过图文消息的 `image_url` 数据 URI 发送给提示词服务。
- 原图、视觉副本不会新增保存到提示词数据库。沿用现有任务去重、有限并发、排队提示和生成文本持久保存；模型请求不自动重试，接口拒绝图片时不自动去掉图片重调。
- 成功提示使用“XXX，小小糯结合原图整理好啦！”。群内帮助与 README 已同步说明。

## 同日实际超时与人工重试

用户截图反馈真实引用图片请求超时。该任务状态为 `failed`，没有生成结果。按用户“重试”指令，原子领取这条失败任务，重新核验原指令及引用图片，仅调用模型一次，临时等待上限设为 120 秒。模型实际用时 53.12 秒，生成 332 字提示词；通过本群官方 Bot 补发，出站记录保存平台消息编号，并已读回核对全文。任务更新为 `sent`，没有再次调用生视频。

此前 45 秒的模型等待上限不足以容纳此次实际响应耗时。现将默认总等待上限调整为 120 秒、建立连接上限设为 15 秒；区分请求超时与连接异常，日志只记录异常类型、是否带图和耗时，不记录原图、正文或密钥。相关 26 项测试通过，超时补丁镜像为 `dzmm-bot:prompttimeout-20261103-150816`。上述实际补发已验证真实群内文本投递，前文合成图测试仍不涉及群消息。
