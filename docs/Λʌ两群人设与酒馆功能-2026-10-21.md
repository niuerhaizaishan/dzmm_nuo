## 酒馆定时问候

北京时间 `Asia/Shanghai`（UTC+8），08:00 早安、00:00 晚安，使用用户文档原文，含开门/
关门提醒，不调用模型。只在瑞雯群已启用且不属于静默监控群时运行。专用功能开关为
`lambda_greetings`；不依赖原先 `push=false`，不顺带打开午安、排行或记忆汇报。

调度在整点后五分钟内检查。每条按北京时间日期去重，发送前持久打点，未确认的结果不由
调度器重复发送。休眠期间到点则跳过，恢复后不补。错过窗口不补发。打点使用独立状态行
`lambda_tavern_greetings`，避免主循环旧群状态快照覆盖它。原有其他群的问候调度保持不变。

## 酒馆合体/分离

- `@Λʌ 回到我身上！`：只有固定 Vv UID 可以休眠；先保存并读回核验状态，再发送原文台词。
- `@Λʌ 分离！`：同一 UID 恢复；即使 `lambda_control` 后来被关闭，仍保留已休眠群的恢复入口。
- 非 Vv 合体：已知男性、已知女性分别回复用户文档指定台词；未知性别使用独立的中性拒绝。
- 非 Vv 分离：拒绝，不改变状态。昵称同名或管理员身份都不取得 Vv 权限。
- 只认新消息正文中完整、直接的指令，兼容中英文感叹号和 @ 后常见空白；
  不读取引用原文，不把普通提及、@其他人或相似名字当作控制命令。
- 控制命令按消息 ID 去重并持久保存最近 64 个 ID。没有发送者 ID 或消息 ID 不改变状态。

专用开关 `lambda_control` 和 `lambda_greetings` 默认允许，但执行入口还硬性检查瑞雯完整
群 ID 与 Λʌ 人设，因此即使其他群配置开启，也不会在 ROSE 或 mr.橘群执行新增功能。

## 休眠与发送

普通分派之前消费控制消息；休眠时停止普通 @、斜杠、管理指令、欢迎、玩法和主动问候。
明确 @ 时只发固定休眠提示，群级冷却 30 秒。收消息与服务健康维护继续运行。

Outbox、发送路由、账号发送出口均检查休眠。控制台词通过仅在当前异步上下文有效的
通行标记发送，不依赖正文匹配。休眠前已排队或明确拒绝待重试的旧消息结案，恢复后
不重放；其他群队列不受影响。已进入平台请求的消息不能凭本地休眠撤回。
