## 本次补丁

- `runtime/generated_media.py`：上传图片时补充平台 Origin/Referer。
- `runtime/routing.py`：在线账号发送生成图片前，先取得平台上传地址或缓存地址；账号连接不可用时明确拒绝，交由服务处理官方兜底。
- `sio_subscribe.py`：图片使用 `type`、平台 `url`、`alt` 和 `reference`，去除原来的 `text`、`caption` 字段。

网页前端发送图片使用平台存储 URL 和 `alt`。本次最终组合“平台 URL + 规范图片字段 + reference”没有再次向真实群投递，以免重复发送已经补发成功的图片。原生图片引用是否被平台接受，仍需后续新任务验收。不存在的房间返回“您不在该聊天室中”，不能作为图片格式或引用已被接受的证据。
