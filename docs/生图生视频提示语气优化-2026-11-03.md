# 生图/生视频提示语气优化

统一小小糯在生成媒体流程中的用户提示：

`XXX，小小糯收到啦！正在努力想象中~前面有 N 张图/个视频排队，另有 M 张图/个视频正在处理。`

提交错误、队列已满、参数错误、生成失败、发送失败和结果待核对提示，也使用 `XXX，小小糯收到啦！不过，...` 的开头；成功发送后使用引用原始指令的确认：`XXX，小小糯已经把图片/视频发好啦！`。其中 `XXX` 来自群成员显示名，名称会去掉换行并限制长度。

图片和视频各自保留原来的数量、失败状态和不重复发送语义，只调整面向群友的文案。
