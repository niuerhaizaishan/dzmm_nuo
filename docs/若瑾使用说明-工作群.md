# 若瑾 · 使用说明（上班如上坟，下班如还魂）

> 适用群：**上班如上坟，下班如还魂**（本群专属）。
> 这份说明按"群里实际生效的开关"写 —— 我在本群**没开**的玩法也一并列出，免得你发了没反应还不知道为什么。
> 群里想直接看：发 **`/说明`** 会得到精简版（就是本文附录 A 那段）。

---

## 1. 她是谁

- **若瑾**，本群的 AI 主持人。基础人设参考小小糯，但**纯 S、异性恋**，说话是命令句：
  不撒娇、不用"哦～／呀／啦"，自称"我"，称你直呼名字。
- 她会记档案：谁发过言、什么性别、签名/简介/性癖（XP）标签。**这些直接影响她怎么骂你、怎么写你。**
- 边界（写死在提示词里）：不涉及未成年、不攻击真实痛点（外貌/家庭/疾病/创伤）。

## 2. 怎么跟她说话

| 你想做的 | 怎么写 | 结果 |
| --- | --- | --- |
| 闲聊、问她问题 | **`@若瑾 你的问题`** | 她按人设回你（群里通常 1～3 句，不写小作文） |
| 玩羞辱 | `/羞辱 点名` | 见 §3.1 |
| 玩发骚 | `/发骚 点名 [自己的玩法]` | 见 §3.2 |
| 玩调教 | `/调教 点名 命令` | 见 §3.3 |
| 查人 / 建档 | `/查 点名`、`/注册` | 见 §4 |

> ⚠️ **不 @ 她、也不是指令的普通发言，她不理**（本群没开"主动接话"）。
> 唯一例外是**调教局里**：目标本人随便回一句（不用 @、不用指令）就能推进下一轮。

## 3. 三个玩法

### 3.1 羞辱

```
/羞辱 临屿           ← 主角写法（也认 /骂 /diss /损 /吐槽）
```

- 她会**先认性别**（档案没有就查一次平台），再按性别分路写：男的、女的都拉到最满、都露骨。
- 会**结合目标最近的发言和档案**，避开上一次用过的角度（连续羞辱不会重复）；
  想换个方向就说：`/羞辱 临屿 专骂他嘴硬`。
- **被羞辱的人 +15 发情值**（后台记账，见 §7）。
- 续写：`/继续`、`/继续 换个角度`、`/续写`（续写目标再 +15、发起人 +10）。
- **特定目标有前缀**：羞辱 **工具熊** 时，消息最前面会自动带 `/talk `（屋主要求的，
  不是给你们的指令，别照抄去发）。
- 一次约 250～350 字，句末偶尔带 💗💦🥵。

### 3.2 发骚

```
/发骚 临屿 自己把话说清楚      ← 点名 + 自定义玩法（自定义部分她只按你写的润色，不加料）
/发骚 临屿                     ← 不写玩法：按目标的 XP/资料挑场景×体位×附加
/发骚                          ← 不点名：群里随机抽一个人
（别名：/体位骰 /场景骰 /涩涩骰）
```

- 输出长这样：第一行 `🎲 临屿 × 【自定义】自己把话说清楚`，下面是正文
  **700～1100 字**（写完为止，不会半句话被截断），句末带 💗💦🥵。
- 抽中的人 **+10 发情值**。
- **接着写**：`/继续`、`/继续 换个姿势`、`/续写` —— 会带着前文接着写（目标 +10、发起人 +10）。
- **不满意就重写**：`/重写`、`/重写 再露骨一点`、`/重新生成`、`/重来`（只对发骚有效）。
- **收尾**：`/结束`、`/停止`、`/停下`、`/终止`（`/发骚结束` 也行）。
- **15 分钟没人接就自动收尾**（防卡死）；发骚进行中 @ 她会先提示"发骚进行中"（打断保护）。

### 3.3 调教

```
/调教 临屿 学狗叫        ← 起一局：点名 + 第一条命令
/调教 临屿              ← 不写命令：她按发起人和目标的 XP 自编一条
/调教开始 临屿 爬过来     ← 同义写法
```

- 起局后她会说「🔗 调教开始。目标：临屿。」+ 第一条命令 + 参与方式。
- **谁都能接话下命令**（包括目标本人）：
  - `/命令 跪好` 或直接 **`/跪好`** —— 局内所有 `/xxx` 都当调教命令；
  - 目标**不用指令**、直接回一句话，就算"应了"，轮到下一条命令（**+20 发情值**）。
- **30 秒没人下命令**，她自己接一条（保持节奏，不用你们催）。
- **收尾**：`/调教结束`（或 `/结束`、`/停止`）；**5 分钟没动静自动收尾**。
- 注意：**局外**发 `/talk`、`/ask` 这类别的机器人的指令，她**完全不回**；`/命令 xxx` 局外会提示"现在没有进行中的调教"。

## 4. 其它可用指令

| 指令 | 作用 |
| --- | --- |
| `/查 点名`（`/whois`、`/资料`） | 看档案：性别、签名、简介、画像、XP；没注册的会给一段 AI 介绍 |
| `/注册` | 给自己建档（`/注册 点名` 只有屋主能用） |
| `/记住 内容`（`/记一下`、`/别忘了`）或 `@若瑾 记住 内容` | 记一条群记忆（她说"记住了。"） |
| `/回忆`（`/记忆`、`/记得什么`） | 翻记忆 |
| `/自我介绍`（`/你是谁`） | 她的自我介绍 |
| `/说明`（`/帮助`、`/功能`、`/指南`） | 精简版说明（附录 A） |

## 6. 为什么她有时不回你

| 情况 | 她为什么不回 |
| --- | --- |
| 没 @ 她、也不是指令 | 本群没开主动接话 |
| 发的是别的机器人的指令（`/talk`、`/ask`…） | 局外一律不理（屋主要求）；局内会当调教命令 |
| 发的是本群没开的玩法（§5） | 关掉的功能一律静默，避免把指令当闲聊答 |
| `/结束` 但没有任何进行中的玩法 | 会回一句「现在没有进行中的玩法。」（不再装死） |
| 玩法进行中你 @ 她 | 会回一句"进行中"的提示（打断保护） |
| 平台抽风/发送失败 | 出站队列会自动重试（只重试"明确被拒"的那类） |

## 7. 常见问答

**发情值是什么？** 后台记账：被羞辱 +15、被抽中发骚 +10、续写 +10、被调教一轮 +20、投票/剧情等另算。
本群**没开**排行与高潮播报，所以你看不到分数 —— 要我开就说。

**档案里有什么？** 昵称、性别、签名、简介、AI 画像、XP 标签、注册时间、发言数。
性别若缺失，她在第一次需要时会去平台查一次并写回档案。

**会不会定时打扰？** 不会。本群没开早安/午安/晚安、骚度排行、每日记忆汇报（推送总开关也是关的）。

**她会说什么不该说的？** 边界写死在提示词里（不碰未成年、不攻击真实痛点）。真出了问题截个图给我。
